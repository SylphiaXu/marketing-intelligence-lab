# 03 · Marketing Analytics

**状态：规划中，暂不开发。**

## 问题

效果差异来自漏斗哪一步？现有证据能支持什么建议，下一次实验应如何区分可能的解释？

## 需求确定后再选择数据

候选包括公开广告活动数据或明确标注的模拟数据。先检查是否包含花费、曝光、点击、转化等所需字段及定义，再确定问题。

实习经历只能帮助抽象业务问题；本仓库使用独立的公开或获授权数据，不上传实习内部数据、客户信息或业务材料。

## 拟采用的方法

1. 定义漏斗分母、转化窗口、成本口径与盈亏平衡假设。
2. 按可用的渠道、人群、创意等字段拆解差异。
3. 区分描述性差异、归因假设与可识别的因果效应。
4. 给出预算情景建议和下一张测试单。

## 计划交付

诊断报告、图表、预算建议与测试单。测试单写明问题、实验单位、主要指标、护栏指标、样本与时长、停止条件，以及回答不了什么。

当前没有数据分析、已实现模型或实验结果。
