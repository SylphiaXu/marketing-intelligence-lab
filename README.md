# Marketing Intelligence Lab

**From consumer signals to marketing decisions.**

A personal portfolio lab exploring how data and AI can support consumer research, brand decisions, and marketing performance analysis.

这是我的 AI 营销实践主线：先理解消费者，再支持品牌决策，最后诊断效果。当前完成的是项目结构与研究计划，尚无可运行原型或已验证结果。

## Evidence and evaluation

- Keep each insight linked to source records and document the sampling method.
- Verify dataset relevance, dates, fields, and reuse terms before analysis.
- Separate observed patterns, hypotheses, model outputs, and recommendations.
- Report baselines, evaluation splits, errors, and limitations when models are implemented.
- Review AI-generated evidence summaries and recommendations before use.
